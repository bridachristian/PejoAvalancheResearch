The project

From observations to operational support

This project investigates how machine learning can support operational avalanche forecasting while maintaining an interpretable link between model predictions and physical snow and weather conditions.

About the research

A Support Vector Machine (SVM) classifier was developed using long-term snow, meteorological and snowpack observations from the Pejo Ski Area in the Italian Alps.

Feature engineering, model evaluation and SHAP explainability were combined to identify the environmental conditions associated with increased avalanche probability.

The model was subsequently tested on an independent winter season and integrated into an operational prototype for scenario-based forecast support.

Methodology

Observations → Features → SVM → SHAP → Forecast support
